# DevOps 工程师常用键盘符号 — 单词 / 读法 / 中文谐音 / 记忆方法

> 使用场景：终端、Shell 脚本、正则、YAML/K8s 配置、Docker/Kubectl 命令、英文技术文档、开会口述命令。
> 排序：按 DevOps 日常使用频率，从高到低。带 `★` 的是每天都要碰的高频符号。

## 一、高频符号（几乎每个命令都会遇到）

| 符号 | 英文单词 | 音标 | 中文谐音读法 | 记忆方法 |
|------|----------|------|--------------|----------|
| `/` | **slash** | /slæʃ/ | 「斯莱士」 | 一条斜线，路径分隔符。**别读成 "solidus"**，口语永远叫 slash，如 `/etc/hosts` |
| `-` | **dash**（连字符 hyphen） | /dæʃ/ | 「达士」 | 短横线。命令短选项 `-v`。口语统称 dash；严格说 hyphen 更短、dash 更长，但没人较真 |
| `--` | **double dash** | /ˈdʌbl dæʃ/ | 「大波 达士」 | 长选项 `--verbose`。有些命令里 `--` 表示「选项到此结束，后面是参数」 |
| `_` | **underscore** | /ˈʌndərskɔːr/ | 「安德斯告尔」 | under(下面) + score(划线) = 下划线。变量命名 `user_name`，演讲/开会口述叫 "underscore" |
| `.` | **dot** | /dɑːt/ | 「道特」 | 一个小点。当前目录、隐藏文件前缀 `.gitignore`。**念点号时要说 "dot"** |
| `..` | **dot dot** | /dɑːt dɑːt/ | 「道特 道特」 | 上级目录 `cd ..`。口语常连读 "dotdot" |
| `~` | **tilde** | /ˈtɪldə/ | 「踢尔达」 | 波浪线，像一条波浪。家目录 `~/.kube/config`。别读成 "wave" |
| `*` | **asterisk**（常读 star） | /ˈæstərɪsk/ | 「爱斯贴瑞斯克」 | 星星。通配符 `*.log`；正则表示「0 个或多个」。**多数人直接说 star** |
| `\|` | **pipe** | /paɪp/ | 「派普」 | 竖线像管道，把前一个命令的输出接到后一个。`ps \| grep nginx`。**这是面试必考名词** |
| `>` | **greater than** | /ˈɡreɪtər ðæn/ | 「格雷特 森」 | 输出重定向（覆盖写）`echo hi > a.txt`。跟 `<` 一起记「大鱼号、小鱼号」 |
| `>>` | **append**（double greater-than） | /əˈpend/ | 「阿彭的」 | 追加写，双大于号，不覆盖 `echo hi >> a.log` |
| `<` | **less than** | /les ðæn/ | 「莱斯 森」 | 输入重定向 `sort < list.txt` |
| `&` | **ampersand** | /ˈæmpərsænd/ | 「安破森得」 | 就是 "and" 的连体艺术字。后台运行 `nginx &`。口语直接说 "and" 也行 |
| `&&` | **double ampersand** | /ˈdʌbl ˈæmpərsænd/ | 「安得 安得」 | 前一条成功才执行后一条 `mkdir a && cd a`。CI 里最常见 |
| `;` | **semicolon** | /ˈsemikoʊlən/ | 「塞米 扣隆」 | semi(半) + colon(冒号) = 半截冒号。多条命令依次执行 `echo a; echo b` |
| `:` | **colon** | /ˈkoʊlən/ | 「扣隆」 | 冒号。**YAML 键值对** `app: nginx`、端口映射 `8080:80`、sed 地址。K8s 面试高频 |
| `'` | **single quote** | /ˈsɪŋɡl kwəʊt/ | 「斯英狗 扣特」 | 单引号：里面的内容原样输出，不做任何展开 `echo '$HOME'` |
| `"` | **double quote** | /ˈdʌbl kwəʊt/ | 「大波 扣特」 | 双引号：里面的变量会被展开 `echo "$HOME"`。单双引号区别是必考题 |
| `$` | **dollar sign** | /ˈdɑːlər saɪn/ | 「刀乐 赛恩」 | 美元符号。Shell 变量 `$PATH`；正则的行尾锚点 `root$`。叫 "dollar" |
| `#` | **hash**（number sign） | /hæʃ/ | 「海士」 | 井号。注释 `# 这是注释`、`#!/bin/bash`。美式叫 pound，程序员统一叫 hash |
| `=` | **equals** | /ˈiːkwəlz/ | 「衣阔子」 | 等号。赋值 `name=nginx`。注意 shell 赋值等号两边**不能有空格** |
| `,` | **comma** | /ˈkɑːmə/ | 「卡玛」 | 逗号。JSON 数组 `[1,2,3]`、多参数分隔。别读 "逗点" |

## 一.5、加减乘除（算术运算符，Linux 命令里天天见）

> `$(( ))` 里做整数运算：`echo $((5 + 3))`；`awk`、`expr`、`dc` 也常用。读法固定，别和通配符/重定向搞混。

| 符号 | 英文单词 | 音标 | 中文谐音读法 | 记忆方法 |
|------|----------|------|--------------|----------|
| `+` | **plus** | /plʌs/ | 「普拉丝」 | 加。`plus` 就是加号本尊；命令行参数里表示「追加/叠加」（如 `-x +y`） |
| `-` | **minus** | /ˈmaɪnəs/ | 「迈纳斯」 | 减。注意和选项前缀区分：`-n` 里的 `-` 读 **dash**，算术里的 `-` 才读 **minus** |
| `*` | **asterisk**（乘法读 multiply） | /ˈæstərɪsk/ | 「爱斯贴瑞斯克」 | 乘。Shell 里必须转义 `\*`（`echo $((3 \* 3))`），否则被当通配符 |
| `/` | **slash**（除法读 divide by） | /slæʃ/ | 「斯莱士」 | 除。读 "divided by"：`10 / 2` → *ten divided by two* |
| `%` | **modulo**（取模，读 percent） | /ˈmɒdjʊloʊ/ | 「毛九娄」 | 取余。`%` 口语叫 percent，但含义是取模 `echo $((7 % 3))` → 1 |
| `=` | **equals** | /ˈiːkwəlz/ | 「衣阔子」 | 等于。比较判断 `[ "$a" -eq "$b" ]`；赋值 `x=5` |
| `!=` | **not equal** | /nɑːt ˈiːkwəlz/ | 「那特 衣阔子」 | 不等于。**注意 Shell 里 `!=` 是字符串比较，数字用 `-ne`** |
| `**` | **power**（double asterisk） | /ˈpaʊər/ | 「泡尔」 | 幂。`echo $((2 ** 10))` → 1024。读 "to the power of" |

> ⚠️ 易混提醒：`*` 在通配符场景读 **star**，在算术场景读 **asterisk/multiply**；`-` 在选项场景读 **dash**，在算术场景读 **minus**。同一个符号，场景决定读法。

## 二、中频符号（正则、条件判断、脚本里常见）

| 符号 | 英文单词 | 音标 | 中文谐音读法 | 记忆方法 |
|------|----------|------|--------------|----------|
| `?` | **question mark** | /ˈkwestʃən mɑːrk/ | 「快斯琛 马克」 | 问号。通配符「匹配单个任意字符」`file?.log`；正则「0 或 1 个」 |
| `!` | **bang**（exclamation mark） | /bæŋ/ | 「棒」 | 感叹号。Shell 历史 `!!` 执行上一条命令；逻辑非 `! grep`。**程序员都叫 bang** |
| `+` | **plus** | /plʌs/ | 「普拉丝」 | 加号。正则「1 个或多个」。注意不是通配符 |
| `%` | **percent** | /pərˈsent/ | 「泼森特」 | 百分号。取模运算、awk/printf 格式符 `%s` |
| `@` | **at sign** | /æt saɪn/ | 「爱特 赛恩」 | 在…处。邮箱 `root@host`；部署时 `user@ip` |
| `[ ]` | **square brackets** | /skwer ˈbrækɪts/ | 「斯阔儿 布莱克茨」 | 方括号。正则字符类 `[a-z]`；Shell 条件判断 `[ -f file ]` |
| `{ }` | **curly braces** | /ˈkɜːrli ˈbreɪsɪz/ | 「克丽 布瑞斯茨」 | 花括号（卷曲的括号）。花括号展开 `{1..3}`；变量引用 `${VAR}`；K8s 模板 {{ }} |
| `( )` | **parentheses** | /pəˈrenθəsiːz/ | 「坡软塞西子」 | 圆括号。子 Shell `(cd dir)`；运算符优先级；正则分组。单数 parenthes**is**，复数 -es |
| `\` | **backslash** | /ˈbækslæʃ/ | 「拜克斯莱士」 | 反着躺的 slash（从右上到左下）。转义字符 `\n`、`\.`；Linux 续行符（Windows 是 `/` 反着用） |
| `^` | **caret** | /ˈkærət/ | 「凯瑞特」 | 小尖帽。正则行首锚点 `^root`；也读 "hat" /hæt/（帽子）。**不是乘方号** |
| `` ` `` | **backtick** | /ˈbæktɪk/ | 「拜克提克」 | 反引号，开口朝左（和单引号方向相反）。命令替换 `` `date` ``，输出作为值 |

## 四、易混对比表（口述/看文档最容易读错的）

| 容易混的符号 | 正确读法 | 错误读法 ❌ | 一句话区分 |
|--------------|----------|-------------|------------|
| `/` vs `\` | slash vs backslash | 都读「斜杠」 | 前倾是 slash，后仰是 **back**slash |
| `'` vs `` ` `` | single quote vs backtick | 都读「引号」 | 单引号朝右开口，反引号朝左开口（tick 反着放） |
| `-` vs `_` | dash vs underscore | 都读「下划线」 | dash 在键盘上方，underscore 在下方（under 在下面） |
| `(` vs `[` vs `{` | parentheses vs brackets vs braces | 都读「括号」 | 圆的=圆括号；方的=方括号；卷的=花括号 |
| `;` vs `:` | semicolon vs colon | 都读「分号/冒号」 | semi(半)colon = 半截冒号 = 分号 |
| `*` vs `^` | asterisk vs caret | 都读「星号/箭头」 | `*` 有 6 个角像星；`^` 是戴帽子 |
| `>` vs `>>` | greater-than vs append | 都读「大于号」 | 双大于号 = 追加，别只说 "greater" |

## 五、正则速查（DevOps 必用 grep/sed/awk/nginx）

| 符号 | 含义 | 记忆 |
|------|------|------|
| `^` | 行首锚点 | Caret 像帽子，帽在最前 = 开头 |
| `$` | 行尾锚点 | Dollar 钱在最后 = 结尾 |
| `.` | 任意一个字符 | 一个小点代表一个坑位 |
| `*` | 前一个字符 0~多次 | Star 星星多多益善 |
| `+` | 前一个字符 1~多次 | 至少 1 次（比 `*` 少一个「0」） |
| `?` | 前一个字符 0~1 次 | 问号 = 可有可无 |
| `[ ]` | 字符集合 | 方括号包一个集合 |
| `( )` | 分组 / 捕获 | 圆括号括一组 |
| `\d` `\w` `\s` | 数字 / 单词字符 / 空白 | d=digit, w=word, s=space |
| `\|` | 或 | 管道也是「或」的意思（二选一） |

## 六、YAML / K8s 专属符号（面试易考）

| 符号 | 名称 | 场景 | 记忆 |
|------|------|------|------|
| `:` | colon | 键值对 `name: nginx` | 冒号后**必须有一个空格** |
| `-` | dash | 列表项 `- name: c1` | 列表项缩进在同一个层级 |
| `#` | hash | 注释 | 井号注释 |
| `\|` | pipe | 多行字符串（保留换行） | 竖线 = 原文输出 |
| `>` | greater-than | 多行字符串（折叠成一行） | 大于号 = 折叠 |
| `&` / `*` | anchor / alias | 锚点复用 `&default` / `*default` | 先 `&` 定义，再 `*` 引用 |
| `{{ }}` | double curly | Helm / 模板变量 `{{ .Values.image }}` | 花括号里是模板引擎在干活 |

*提示：给老外口述命令时，路径、端口、变量名这些关键词加上符号读法，比光拼字母更专业。例：`cat~/.bashrc pipe grep PATH` → 读作 "cat tilde dot bashrc pipe grep PATH"。*
